# Pinhole

面向多模态智能体的照片地理定位 skill。通过画面线索、公开资料检索与空间几何核验，查找拍摄地点，并给出位置范围、误差依据和可追溯证据。

- **线索分析**：从地貌、建筑、道路和遮挡关系中发现线索，逐步缩小候选范围。
- **交叉核验**：结合地图、实景与可观测几何比较候选，检查矛盾和替代解释。
- **证据交付**：报告定位范围、镜头朝向和核验依据；条件允许时生成证据图。

## 安装

需要 Node.js ≥22.20.0，通过 [skills CLI](https://github.com/vercel-labs/skills) 安装：

```sh
npx skills@latest add zhanpoint/Pinhole --skill pinhole
```

默认安装到当前项目；加 `-g` 安装到用户目录，加 `-a <agent>` 指定宿主。支持的宿主与参数见 [CLI 文档](https://github.com/vercel-labs/skills#supported-agents)。

## 使用

在支持图片输入的智能体中附上照片，明确请求使用 `pinhole`：

> 使用 pinhole 分析这张照片的拍摄地点。请给出候选位置、支持与反对证据，以及能够确认的位置范围；条件允许时补充镜头朝向和证据图。

技能提供分析与核验方法，图片查看、联网检索、地图和计算由宿主工具完成。安装后按宿主要求重载或开启新会话，确认技能已加载。

## 结果说明

- 精度取决于照片线索与可用参照；证据不足时保留候选，报告已确认范围与待核验项。
- 数值测量和证据图须来自实际工具与真实资料；不伪造坐标精度、测量结果或底图。
- 证据档位（Tier）表示证据强度，不代表定位正确率；安装成功也不代表已通过准确率评测。

## 更新与卸载

以下命令管理当前项目中的安装：

```sh
npx skills@latest ls
npx skills@latest update pinhole -p
npx skills@latest remove pinhole -y
```

用户级安装：检查和卸载加 `-g`，更新将 `-p` 换成 `-g`。
